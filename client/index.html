Design & Model Pre-Check Checklist

Please verify each item before submitting your model for slicing and printing.

Model file format is saved as .STL or .3MF
Model dimensions fit within the printer bed volume limits (Bambulab A1: 256mm × 256mm × 256mm)
Model orientation has been optimized for bed adhesion and strength
G-code / Sliced file generated using approved lab slicer settings (Bambulab Studio)
Print bed is clean and completely clear of previous prints
